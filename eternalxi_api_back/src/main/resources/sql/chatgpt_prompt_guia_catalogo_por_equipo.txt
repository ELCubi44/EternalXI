────────────────────────────────────────────────────────────────────────────────
B) ESQUEMA REAL DE TABLAS (MySQL 8 — NO INVENTES COLUMNAS)
────────────────────────────────────────────────────────────────────────────────

Regla de oro: la PRIMARY KEY de temporadas, equipos, jugadores y supertecnicas
se llama **`id`**. Las FKs en tablas hijas sí se llaman id_temporada, id_equipo,
id_jugador, id_supertecnica — pero **nunca** uses id_jugador ni id_supertecnica
como nombre de columna al hacer SELECT sobre la tabla padre.

--- temporadas ---
  id              INT AUTO_INCREMENT PRIMARY KEY
  nombre          VARCHAR          fallback español
  foto            VARCHAR NULL

--- temporada_traduccion ---
  id_temporada    INT FK → temporadas.id
  locale          VARCHAR(5)       'es' | 'en'
  nombre          VARCHAR(100)
  PRIMARY KEY (id_temporada, locale)

--- equipos ---
  id              INT AUTO_INCREMENT PRIMARY KEY
  nombre          VARCHAR          fallback español
  id_temporada    INT FK → temporadas.id
  foto            VARCHAR NULL

--- equipo_traduccion ---
  id_equipo       INT FK → equipos.id
  locale          VARCHAR(5)
  nombre          VARCHAR(120)
  PRIMARY KEY (id_equipo, locale)

--- jugadores ---
  id              INT AUTO_INCREMENT PRIMARY KEY
  id_equipo       INT FK → equipos.id
  nombre          VARCHAR          nombre completo — NO traducir
  pila            VARCHAR          apodo — NO traducir
  dorsal          INT
  descripcion     TEXT NULL        → SIEMPRE NULL en INSERT
  valoracion      INT
  genero          ENUM('H','M','?')
  posicion        ENUM('POR','DEF','MED','DEL')
  pais            VARCHAR(64)      código ISO 2 letras: ES, FR, JP, BR...
  altura          SMALLINT UNSIGNED   centímetros
  estilo          ENUM('PICARO','PRECISO','POTENTE','VALIENTE','AGIL')
  foto            VARCHAR NULL

--- jugador_traduccion ---
  id_jugador      INT FK → jugadores.id
  locale          VARCHAR(5)
  descripcion     TEXT             bio ES / bio EN
  PRIMARY KEY (id_jugador, locale)

--- supertecnicas --- (catálogo GLOBAL, reutilizable entre jugadores)
  id              BIGINT AUTO_INCREMENT PRIMARY KEY
  nombre          VARCHAR(128)     clave interna snake_case, SIN acentos
  potencia        TINYINT UNSIGNED
  tipo            ENUM('REGATE','DEFENSA','PARADA','TIRO')
  estilo          ENUM('PICARO','PRECISO','POTENTE','VALIENTE','AGIL')
  UNIQUE (nombre, potencia, tipo, estilo)

--- supertecnica_traduccion ---
  id_supertecnica BIGINT FK → supertecnicas.id
  locale          VARCHAR(5)
  nombre          VARCHAR(128)     nombre visible traducible
  PRIMARY KEY (id_supertecnica, locale)

--- jugador_supertecnica --- (exactamente 4 filas por jugador)
  id              BIGINT AUTO_INCREMENT PRIMARY KEY
  id_jugador      INT FK → jugadores.id
  id_supertecnica BIGINT FK → supertecnicas.id
  orden           TINYINT UNSIGNED   1, 2, 3 o 4
  UNIQUE (id_jugador, orden)
  UNIQUE (id_jugador, id_supertecnica)

────────────────────────────────────────────────────────────────────────────────
C) ERRORES PROHIBIDOS (causan 0 enlaces en jugador_supertecnica)
────────────────────────────────────────────────────────────────────────────────

  INCORRECTO                              CORRECTO
  ─────────────────────────────────────   ─────────────────────────────────
  SELECT id_jugador FROM jugadores        SELECT id FROM jugadores
  SELECT id_supertecnica FROM supertecnicas   SELECT id FROM supertecnicas
  j.id_jugador en JOIN jugadores          j.id
  e.id_equipo como PK de equipos          e.id
  JOIN equipos e ON e.id_equipo = ...     JOIN equipos e ON e.id = j.id_equipo
  Olvidar SET @id_jugador = LAST_INSERT_ID()   Obligatorio tras cada INSERT jugador
  Un solo SELECT para las 4 ST            Cuatro SELECT id INTO @st1..@st4
  INSERT jugador_supertecnica sin @stN    @stN debe venir de SELECT id INTO

Si @st1..@st4 quedan NULL, jugador_supertecnica inserta 0 filas útiles.
Warning "Duplicate entry" (1062) con INSERT IGNORE es normal al re-ejecutar.

SECCIÓN 2 — TEMPORADA (buscar o crear, idempotente)
═══════════════════════════════════════════════════════════════════════════════

-- === TEMPORADA: Eterno Campeon / Eternal Crown ===
SET @id_temporada = NULL;

SELECT tt.id_temporada INTO @id_temporada
FROM temporada_traduccion tt
WHERE tt.locale = 'es' AND tt.nombre = 'Eterno Campeon'
LIMIT 1;

INSERT INTO temporadas (nombre, foto)
SELECT 'Eterno Campeon', NULL
FROM DUAL
WHERE @id_temporada IS NULL;

SET @id_temporada = IFNULL(@id_temporada, LAST_INSERT_ID());

INSERT IGNORE INTO temporada_traduccion (id_temporada, locale, nombre) VALUES
(@id_temporada, 'es', 'Eterno Campeon'),
(@id_temporada, 'en', 'Eternal Crown');

SECCIÓN 5 — REUTILIZAR SUPERTÉCNICAS YA EXISTENTES
═══════════════════════════════════════════════════════════════════════════════

Varios jugadores (incluso de otros equipos) pueden compartir la misma ST
(ej. pared_de_tiza, rastro_de_chispa, chut_de_bolsillo).

  • INSERT IGNORE INTO supertecnicas → si ya existe, no inserta (OK)
  • SELECT id INTO @stN ... → sigue encontrando la fila existente (OK)
  • INSERT IGNORE INTO supertecnica_traduccion → no dupliques si ya existe
  • INSERT INTO jugador_supertecnica → SIEMPRE crea el enlace jugador↔ST

El WHERE del SELECT id INTO debe incluir las 4 columnas del UNIQUE:
  nombre + potencia + tipo + estilo

SECCIÓN 6 — VERIFICACIÓN OBLIGATORIA AL FINAL DEL SCRIPT
═══════════════════════════════════════════════════════════════════════════════

Incluye SIEMPRE estas dos queries al final (sustituye [NOMBRE CLUB ES]):

-- === VERIFICACIÓN ===
-- Jugadores con distinto de 4 supertécnicas (debe devolver 0 filas):
SELECT j.nombre, COUNT(js.id) AS num_st
FROM jugadores j
JOIN equipos e ON e.id = j.id_equipo
JOIN equipo_traduccion et ON et.id_equipo = e.id AND et.locale = 'es'
LEFT JOIN jugador_supertecnica js ON js.id_jugador = j.id
WHERE et.nombre = '[NOMBRE CLUB ES]'
GROUP BY j.id, j.nombre
HAVING COUNT(js.id) <> 4;

-- Total enlaces jugador_supertecnica (debe ser [N] × 4):
SELECT COUNT(*) AS total_enlaces
FROM jugador_supertecnica js
JOIN jugadores j ON j.id = js.id_jugador
JOIN equipos e ON e.id = j.id_equipo
JOIN equipo_traduccion et ON et.id_equipo = e.id AND et.locale = 'es'
WHERE et.nombre = '[NOMBRE CLUB ES]';

Resultado esperado:
  • Primera query: **0 filas**
  • total_enlaces = **[N] × 4** (ej. 19 jugadores → 76)
